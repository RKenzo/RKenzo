![Backend](https://img.shields.io/badge/Backend-FFCF1F?style=for-the-badge)

Software engineer. I build products end to end — and care the most about the parts nobody sees.

I care a lot about **architecture**: business logic that outlives frameworks, dependencies pointing inward, code that stays easy to change years later.

**Security is a default, not a feature.** The boring details nobody notices are exactly the ones I refuse to skip.

And I believe **simple beats clever**: small changes over big rewrites, root causes over symptoms, boring code that works over smart code that surprises.

Most of my work lives in private repositories, running in production for real users and companies. What you see here is just the tip of the iceberg.
